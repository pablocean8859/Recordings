# Recordings
Alarm Clock Recordings for use in software.

1) Quad-Tone Casio TQ-140 

This was a common quad-tone alarm in appliances and vehicles (Honda, Acura) in the 1990's.
The Casio TQ-140 Alarm Clock has the same tone generator circuit.

Clock was disassembled, leads to piezo ran to stereo plug into a DAC/recording interface.
Alarm was triggered, waveform captured. Filters were applied, track mastered to recreate that familiar timbre (preserving harmonics) on any speaker output. Gated, output dithered with airWindows plugin 'Ditherbox.'

If you use these (this for now) recording inside a software package, please add an entry in your about page.

More recordings to come. Thank You!
